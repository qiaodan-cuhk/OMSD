# Included multi-agent environments

The MPE package contains OMSD's task scenarios based on the public
[Multi-Agent Particle Environment](https://github.com/openai/multiagent-particle-envs)
and [Shariq Iqbal's fork](https://github.com/shariqiqbal2810/multiagent-particle-envs).
Its [MIT license](mpe/LICENSE) retains the OpenAI and Shariq Iqbal notices.
Imports are namespaced within OMSD.

The multi-agent MuJoCo 2.1 wrapper and its license are retained under
`third_party/multiagent_mujoco`. The `omiga` branch provides its separate
MuJoCo environment and runtime requirements.
